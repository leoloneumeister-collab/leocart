# leocart

Three browser games, all fully procedural (geometry, music and sound are generated in code).

| Game | Folder | Live path |
|---|---|---|
| Leocart, 3D kart racer | repo root | `/` |
| Shadow Protocol, 3D military shooter | [`shooter/`](shooter/README.md) | `/shooter/` |
| LANEFALL, 5v5 MOBA vs bots | [`moba/`](moba/README.md) | `/moba/` |

Run the kart game: `npm install && npm run dev`.
Run the shooter: `cd shooter && npm install && npm run dev`.
Run the MOBA: `cd moba && npm install && npm run dev` (port 5174).

GitHub Pages deploys all three from `main` (Settings, Pages, Source: GitHub Actions).
